# Bengt Dahlgren Github Org

This organisation brings together repositories developed by people working across
energy, buildings, GIS and engineering. Projects can cover different topics and
use different tools; each repository provides its own details, documentation and
instructions.

## Topics and repositories

### Energy, buildings and thermal-system simulation

The current repositories in this area focus on geothermal boreholes and
ground-source heat pump systems, including TRNSYS components for modelling
borehole fields:

- [trnsys-parallel-boreholes](https://github.com/Bengt-Dahlgren-Stockholm-Geo/trnsys-parallel-boreholes)
  — simulates parallel-connected boreholes installed at the same time.
- [trnsys-previous-load](https://github.com/Bengt-Dahlgren-Stockholm-Geo/trnsys-previous-load)
  — supports simulations that account for the historical thermal load on a
  parallel borehole field.
- [trnsys-bns](https://github.com/Bengt-Dahlgren-Stockholm-Geo/trnsys-bns)
  — models parallel boreholes installed in two phases.
- [trnsys-neighbourhood](https://github.com/Bengt-Dahlgren-Stockholm-Geo/trnsys-neighbourhood)
  — models a borehole and its thermal interaction with neighbouring boreholes.

### GIS and spatial analysis

Repositories in this area may include geospatial data, analysis, tools and
workflows for location-based engineering and energy questions.

### Engineering and technical tools

Repositories may also contain engineering calculations, simulation components,
data-processing tools and supporting workflows. Technologies used by the
current geothermal projects include TRNSYS, Python and, in some projects,
Julia.

## Finding your way around

The topics above describe the current project areas, not limits on what belongs
in the organisation. For the scope, setup and usage of a particular project,
start with that repository's README.
